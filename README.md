# LabSound – MenoresLAB SpA.

## Descripción del proyecto
LabSound es un laboratorio virtual interactivo orientado a estudiantes de primero medio, diseñado para facilitar el aprendizaje de las ondas sonoras y la relación entre frecuencia y tono.

## Objetivo
Permitir que los estudiantes experimenten con sonidos graves y agudos, visualicen sus características físicas y analicen los resultados mediante gráficos y mediciones cuantitativas.

## Funcionalidades
- Captura de audio mediante el micrófono del dispositivo.
- Modo demostración con frecuencias controladas.
- Visualización de ondas sonoras en el dominio del tiempo.
- Visualización del espectro de frecuencias.
- Registro de mediciones.
- Presentación de indicadores estadísticos.

# Acceso a la aplicación
https://proyecto-innovacion-lab.netlify.app/

## Instrucciones de uso
1. Abrir LabSound desde el enlace.
2. Seleccionar una frecuencia de referencia.
3. Activar el micrófono o el modo demostración.
4. Observar los gráficos de onda y espectro.
5. Registrar las mediciones.
6. Repetir el procedimiento con otras frecuencias.
7. Comparar los resultados obtenidos.

## Instalación y ejecución local
1. Descargar el repositorio desde GitHub mediante **Code → Download ZIP**.
2. Extraer los archivos.
3. Abrir la carpeta que contiene la aplicación.
4. Abrir `index.html` en un navegador compatible.

**Nota:** Algunas funciones, especialmente el acceso al micrófono, pueden requerir ejecutar la aplicación desde un servidor local o HTTPS.

## Tecnologías
